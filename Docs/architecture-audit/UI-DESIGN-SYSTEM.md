# 架构审计查看器视觉规范（2026-10-14，极简深色版）

## 设计目标

页面首先让人找到搜索、当前对象和关系证据。参考用户提供的 ChatGPT 外观设置截图：近黑底、灰色容器、明亮文字、少量紫色选中提示。它是一件长期阅读的开发工具，不使用霓虹、发光或持续动画。页面中的“区域 1～7”继续对应[使用说明](VIEWER-MANUAL.md)。

**白话解释**：先看清内容和下一步能点哪里，再看颜色。

## 颜色与字体

| 用途 | 当前值 | 具体用法 |
|---|---|---|
| 页面与画布 | `#181818` | 统一近黑背景，网格极淡。 |
| 左右面板 | `#202020` | 用轻量分隔线和画布区分。 |
| 普通卡片和输入框 | `#272727` | 鼠标悬停时略变亮。 |
| 分隔线 | `#393939` 左右 | 不给每段文字加厚边框。 |
| 主要文字 | `#f5f5f5` | 标题、节点名称、重要操作。 |
| 次要文字 | `#b7b7b7` 左右 | 路径、说明和辅助信息仍需可读。 |
| 交互强调 | `#b58bfa` | 当前对象、选中结果、键盘焦点、被选中的线。 |
| 待验证 | 蓝灰 `#a9c4da` + 空心圆点 + “待验证”文字 | 与紫色交互选中分开。 |
| 问题提示 | 低饱和琥珀 | 问题编号与风险；最终结论仍以文字和证据为准。 |

正文从 14px 起，节点名称为 13px；路径与证据使用本机等宽字体。字体栈使用系统字体和微软雅黑，不联网加载字体。标题、分区、正文、标签逐级减弱，但不靠大量 10px 小字塞信息。按钮、输入框与卡片以 8～12px 适度圆角和一致间距组织；右侧详细说明主要靠小标题和留白分组。

## 图上的线怎样读

| 你看到的东西 | 含义 | 不应误读成 |
|---|---|---|
| 紫色描边的卡片或线 | 当前选中，方便定位。 | 该对象已经运行通过。 |
| 蓝灰空心点与“待验证” | 关联证据仍缺运行时验证。 | 当前选中。 |
| 琥珀问题标记 | 关联风险、设计关切或已确认问题。 | 每条相关线都是缺陷。 |
| 有箭头的线 | 数据记录的来源指向目标。 | 游戏调用先后或运行通过。 |
| 无箭头的总览/文本线索 | 系统汇总或 C# 名称匹配。 | 已确认的方法调用。 |
| 实线、虚线、点线 | 文件/源码证据、文本线索、源码已核但运行待证等不同证据层级。 | 单凭线型得出全部验证结论。 |

节点仍显示 `CS`、`PF`、`GO`、`CP` 等类型缩写，名称放大；长名称在卡片内按真实宽度截短，完整名称在悬停提示和右侧详情中可查。多条平行关系错开，线的可点击区域比可见线更宽。选中边紫色突出，其他连接退为中性灰；风险与待验证仍通过标记、文字和线型辨别。

## 三栏与交互

- 左栏搜索与示例常驻顶部；首次使用的 3 步说明可展开，默认收起；“按流程或问题编号找”直接带到进阶筛选。搜索结果与筛选共用左栏滚动，避免两个滚动容器抢滚轮。选中结果有紫色背景和边线。路径允许换行，完整内容也可在右侧复制。
- 中央保持系统总览和“左边指向当前对象、右边由当前对象指向目标”的局部图。方向按钮、缩放、拖动画布与还原视图都在原有操作范围。画布灰黑，淡网格不压过卡片。
- 右栏以对象名称和类型开头，再给“它是什么、在项目哪里、关联问题、上游、下游、下一步”。源码路径可复制；点线后给证据类型、验证状态和具体来源。详情过长时单独滚动。
- 1440/1280/1920px 保持三栏；约 1024px 时详情移至图谱下方。窄桌面和浏览器放大后，先保证内容不横向溢出，再以滚动访问详情。键盘焦点为明显的紫色轮廓；`prefers-reduced-motion` 关闭非必要过渡。

## 验收边界

颜色和布局不改变 `graph.json` 的边、证据与问题状态；生成源是 [viewer-template.html](../../Tools/ArchitectureAudit/viewer-template.html)，运行 `scan.py` 后才更新离线页。浏览器操作通过只证明查看器本身，不能替代 Unity Inspector 或 Play Mode。此次未新增第三方字体、图标、图库、CDN 或前端框架。
