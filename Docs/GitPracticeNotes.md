# Git Practice Notes

## Current Goal

Use this Unity RPG demo project to practice real Git project management.

## Repository Status

- The project has been initialized as a local Git repository.
- The first commit saved the Unity project baseline.
- This note is created on a feature branch for branch practice.

## Key Ideas

- The working tree is where files are edited.
- The staging area stores changes prepared for the next commit.
- A commit records a stable project snapshot in the local repository.
- A branch points to a commit and can move forward independently.
