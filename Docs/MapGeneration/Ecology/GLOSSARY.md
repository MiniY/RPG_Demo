# RPG_Demo 生态分区语义

这里只解释本专项的游戏概念。实现字段、算法与未决政策见DESIGN/DECISIONS，词汇不代替设计批准。

## Language

**Ecological Type（生态类型）**：一种怪物及其确定颜色所构成的常驻身份；同种不同颜色在本设计中算不同类型。
_Avoid_：把物种数组中的随机颜色变体当作同一个常驻生态类型。

**Home Territory（常驻领地）**：某类型在一张地图中获得的日常活动空间。个体临时离开，不改变归属。
_Avoid_：用怪物当前站位反推老家。

**Chase Envelope（追击允许范围）**：怪物离开老家追击时允许暂时活动的空间和时间限制。
_Avoid_：把短暂过境算成常驻混住。

**Safety Exclusion（安全禁入范围）**：安全主体及其外围怪物避让缓冲共同形成的怪物禁入空间；战斗保护与之使用相同空间，但属于独立职责：区域禁入管移动，双向隔离管当前玩家/怪物近战。
_Avoid_：用怪物不能进入直接推导玩家无敌。

**Merchant Safety Area（商人安全区）**：首版放置唯一商人的安全主体。
_Avoid_：把唯一商人模板在多处复制视为一个实例。

**Rest Safety Area（休息安全区）**：首版另一处没有商人的安全主体，只承诺安全落脚空间。
_Avoid_：自动附加回血、存档、篝火或传送功能。

**Neutral Transition（中立过渡地带）**：按Q14=B确认：没有常驻怪物归属、仍可被合法追兵经过的连接地带；过境不重置距离/时间或改变安全禁入。
_Avoid_：把没有常驻怪物叫安全区。


**Protected Combat Area（战斗保护范围）**：安全主体及整个避让缓冲共同构成的当前玩家/怪物近战停战空间。进入会使本次尚未结算伤害失效，离开不会恢复旧一击。
_Avoid_：把已取消攻击理解为离区后仍可恢复，或把保护扩成所有静物/未来武器的无敌。
