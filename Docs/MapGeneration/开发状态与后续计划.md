# 地图生成系统开发状态与后续计划

## 一、当前完成状态

当前 `Generator Version（生成器版本）` 为 `6`，已经完成：

- 可复现的 Seeded Generation（带种子生成）。
- 高度、湿度和温度多通道地形分类。
- 深水、浅水、沙地、草地、森林、山地和道路。
- 自然区域清理、出生保护、深水边界和出口道路。
- 出生点到出口的可达性修正。
- 水、沙、草、山的嵌套过渡带。
- 分层地形自动瓦片和隐藏碰撞层。
- 两格通路宽度与错位通路 `2×2 Clearance（2×2 净空块）`。
- 数据驱动 Minimap（小地图）。
- 出生点、出口和玩家位置标记。
- Fog of War（战争迷雾）与圆形探索范围。
- 树木、灌木、散落岩石简单装饰。
- 树冠遮挡、树桩碰撞和独立装饰随机流。
- 地图相机边界限制。
- Editor Migration（编辑器迁移）工具和 Edit Mode Test（编辑模式测试）。

## 二、本次远程发布决策

旧地图工作树中存在两个未提交变化，本次发布均不包含：

1. 默认 `Seed（随机种子）` 从 `-1631670606` 变为 `233491381`。该变化没有对应缺陷、设计说明或回归测试，被视为临时随机化结果。
2. 测试场景的 `Chunk Culling Bounds（分块剔除边界）` 从 `(0, 0, 0)` 变为 `(0.5, 0.5, 0)`。该变化没有对应渲染问题和验证证据，被视为 Unity Editor（Unity 编辑器）序列化变化。

远程发布继续使用已提交的稳定配置，不把临时场景状态混入正式分支。

## 三、现有验证资产

自动化测试覆盖：

- 相同种子的确定性。
- 出生保护区、深水边界和出口可达性。
- 地形阈值校验与多地形生成。
- 自然区域清理和分层地形拓扑。
- 高地崖面不覆盖水域。
- 水、沙、草、山嵌套关系。
- 单格通路、错位通路和 `2×2 Clearance（2×2 净空块）`。
- 用户报告的问题种子和 64 个批量种子。
- 简单装饰的确定性、完整占地、素材映射、碰撞与随机流隔离。
- 小地图颜色、坐标转换和战争迷雾探索状态。
- 测试场景中的八个 Tilemap（瓦片地图）、排序层和碰撞组件。

测试源码存在不等于最近一次运行已经通过。发布后仍应在目标 Unity Editor（Unity 编辑器）中执行全部 Edit Mode Test（编辑模式测试）和 Play Mode（播放模式）手工验证。

## 四、当前已知限制

1. `MapGenerationControllerEditor（地图生成控制器编辑器）` 的 Undo（撤销）快照只覆盖五个地形 Tilemap（瓦片地图），尚未覆盖三个简单装饰 Tilemap（瓦片地图）。
2. 地图生成在主线程同步完成；当前默认 `64×64` 尺寸可接受，更大地图需要性能测量后再决定是否分帧或异步化。
3. 战争迷雾探索状态目前只存在于内存中，没有接入统一存档。
4. `MapData（地图数据）` 目前只保存地形、出生点和出口，不保存复杂装饰、怪物、采集物或任务对象。
5. `MapGeneration（地图生成分支）` 与 `main（主分支）` 分开演进；主分支新增的怪物人工智能和伤害系统尚未在随机地图测试场景中做集成验证。

## 五、后续开发顺序

1. 补齐三个简单装饰层的 Undo（撤销）记录，并验证生成、清空和重新生成可以完整撤销。
2. 实现 `MapComplexDecorationData（地图复杂装饰数据）`。
3. 建立固定祭坛和岩塔模板，模板内部结构不参与随机拆分。
4. 为复杂装饰增加入口、出口、触发器、交互点和状态。
5. 实现祭坛 `F` 键交互、浮动感叹号和全图战争迷雾解除。
6. 实现 `Gameplay Spawn（玩法对象生成）`，包括怪物、采集物和任务对象的合法生成区域。
7. 将世界随机种子、探索状态和必要地图状态接入统一存档。
8. 扩大 Batch Seed Quality Test（批量种子质量测试）范围，并输出地形比例、可达面积、装饰密度和生成耗时统计。
9. 在明确需要集成时，再单独评估与 `main（主分支）` 的 Merge（合并）策略；该步骤不属于当前远程发布。
